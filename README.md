## Com publicar a GitHub Pages

1. Crea un repositori nou a [github.com](https://github.com)
2. Puja el contingut d'aquesta carpeta `web/` a l'arrel del repositori
3. Ves a **Settings → Pages**
4. A *Source*, selecciona la branca `main` i la carpeta `/ (root)`
5. Guarda. En uns minuts la web estarà disponible a `https://<usuari>.github.io/<repositori>/`

## Sobre el projecte

El KIDS Living Lab combina disseny estratègic, pensament especulatiu i pedagogia maker per generar eines que qualsevol facilitador pot usar en contextos educatius formals i informals.

La metodologia s'estructura en dues dinàmiques principals:
- **Canvas 1 — Mapa de Senyals**: el grup classifica els senyals febles per rellevància i interès respecte al repte treballat.
- **Canvas 2 — Escenaris de Futur**: el grup construeix un escenari especulatiu a 100 anys i defineix 3 accions concretes a 10 anys vista.
